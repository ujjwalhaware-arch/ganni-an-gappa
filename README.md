# गाणी आणि गप्पा (Gaani Ani Gappa) — Marathi Nostalgia Radio 🎶🚩

A glassmorphic single-page Marathi nostalgia music player application built with **Next.js 15 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and driven by the **YouTube IFrame API**.

---

## ✨ Features

- 📻 **100+ Marathi Golden & Modern Hits**: Curated playlists spanning Golden Era classics (*Lata Mangeshkar, Asha Bhosle, Sudhir Phadke*), Lavani & Folk, Blockbuster Movie Hits (*Sairat, Natarang, Jogwa*), Trending Pop (*Sanju Rathod, Ajay-Atul*), Bhavgeet / Devotional, and Konkani / Koli culture.
- 🎨 **Festive Marathi Visuals**: Cinematic Gudi Padwa Maharashtra festival background with subtle retro film grain turbulence overlay.
- 💿 **Spinning Vinyl Disc**: Responsive animated vinyl record displaying live video playback.
- 📜 **"सर्व गाणी" Searchable Catalog Drawer**: Instant real-time search across all tracks by title, artist, or movie name.
- ⏰ **Live IST Clock & Realtime Listener Pill**: Dynamic Indian Standard Time clock and animated live listener counter.
- 🎛️ **Full Playback Controls**: Play/Pause, Next, Previous, Shuffle, Mute/Unmute, and Draggable Seekbar with elapsed/duration time.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
